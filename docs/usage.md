# 작문 사용법

1. **작문 훈련**에서 English / 한국어를 고르고 직접 씁니다. 영어는 Basket 표현을 선택할 수 있습니다.
2. 작성 방법을 선택하고 **GPT 첨삭받기**를 누릅니다. 최초 글이 보존됩니다.
3. 열린 ChatGPT에 자료를 붙여넣습니다. 받은 JSON 결과를 앱의 **첨삭 자료 · 받은 결과**에 붙여넣고 **첨삭 저장**을 누릅니다.
4. 잘한 점과 다듬을 점을 읽고 자신의 말로 **다시 쓰기**를 합니다. 원문은 유지됩니다.
5. **학습 완료**로 마칩니다. 영어 글은 **이 글로 1분 대화**로 이어갈 수 있습니다.

**독서에서 가져오기**는 사용자가 읽은 짧은 원문·표현만 직접 담습니다. 저장 후 **새 작문에 사용** 또는 **문장 변형**을 선택합니다.

**이번 주 독립 작문**은 도움 없이 새 주제로 씁니다. 주마다 같은 조건을 유지합니다. 일반 연습은 Level·난이도·문장 수를 조절할 수 있습니다.

**성장 기록**에서 언어·일반/주간·7/30/90일·비교 조건을 고릅니다. 점수 없는 날을 0점으로 표시하지 않습니다. GPT 예시를 옮긴 글이나 자료 부족 글은 독립 성장 그래프에서 제외합니다.

설정의 **백업 받기**에 작문도 함께 저장됩니다. 기록은 이 브라우저에만 있으므로 기기를 바꾸기 전에 백업해 주세요. 저장에 실패하면 글을 복사해 보관하고 저장을 다시 누르세요.
