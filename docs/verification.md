# 검증 기록 · Writing Studio

2026-10-09. 개발 중 시험 자료만 사용했으며 실제 사용자 작문·ChatGPT 계정에 접근하거나 전송하지 않았다.

## 확인한 범위

- 기존 단위/통합 검사: 한국 시간 날짜, 숙달·복습, 결과 중복, Level, 백업, API 비사용.
- 새 단위 검사: 최초 원문 보존, 결과 식별값·점수 검증, 독립/재작성 분리, 짧은 글 신뢰도, 주간 새 주제·같은 난이도, 7/30/90일, 언어 분리, 독서 중복, 백업 충돌 사본·재가져오기.
- `tools/browser-check.mjs`: 기존 표현·복습·회화·Level·성장·모바일·오프라인을 실제 브라우저에서 확인.
- `tools/studio-browser-check.mjs`: A 수집 표현 선택/작성, B 원문 보존과 첨삭/재작성, C 날짜별 평가 조회, D 비교 조건 분리, E 이전 형식 학습 데이터 보존, F 잘못된 GPT 결과/오프라인/저장 실패 때 작성 글 보존 및 복구.
- `tools/writing-preview.html`: 네 디자인 시안의 모바일 폭 확인.

실제 ChatGPT의 평가 품질·모델별 응답 안정성·사용자의 장기 학습 효과는 자동 검사로 검증하지 않았다. 브라우저 검사는 ChatGPT 이동과 구조화된 시험 응답을 사용한다. 앱이 자동 첨삭하거나 실제 계정에서 결과를 자동 회수한다는 주장은 하지 않는다.

실행: `node --test tests/*.test.mjs`, `node tools/browser-check.mjs`, `node tools/studio-browser-check.mjs`. 화면 캡처는 `BASKET_SCREENSHOTS=1`에서만 생성한다. 최종 실행 결과와 배포 여부는 작업 완료 시 이 문서에 덧붙인다.

최종 기능 검사: 36개 통과(0 실패), 기존 회화 브라우저 검사 통과, 새 작문 A–F 브라우저 검사 통과. 마지막 회귀 검사에서 저장 실패 후 재저장·재실행으로 원문이 복원됨을 확인했다. 신규 화면의 보조 글자 대비를 보강했다. 기존 글자 크기의 일괄 변경은 사용자 디자인 선택을 기다리는 상태다.
