# 작문 평가 기준 v1

평가는 사용자의 기존 ChatGPT 계정에서 받는 **학습 참고 평가**다. 공인 영어 등급이나 실제 언어 능력 측정으로 해석하지 않는다. 앱은 점수를 만들어내지 않고 가져온 결과를 검증·보관한다.

| 영어 `basket-writing-en-v1` | 배점 |
|---|---:|
| 문법 정확성 | 25 |
| 표현력 | 20 |
| 문장 구성 | 20 |
| 내용과 논리 | 20 |
| 수집 표현 활용 | 15 |

| 한국어 `basket-writing-ko-v1` | 배점 |
|---|---:|
| 생각의 명료성 | 25 |
| 내용과 논리 | 25 |
| 문장 연결 | 20 |
| 어휘의 적절성 | 15 |
| 맞춤법·문법 | 15 |

총점은 검증된 세부 점수의 합이다. 추가 점수·음수·배점 초과·알 수 없는 표현 ID를 거부한다. 수집 표현을 고르지 않은 영어 글의 활용 점수는 0점으로 요청한다. 문장 수만 늘린 글은 가점하지 않는다. 수정 예시는 사용자의 원뜻과 표현을 유지하며, 개선점은 최대 3개다.

## 공정한 비교

- 언어·일반/주간·Level·난이도·권장 문장 수·기준 버전이 같아야 비교한다.
- 최초 작성본의 `도움 없이 직접 작성` 확인과 평가 신뢰도가 필요하다. 이는 사용자 신고이며 앱이 외부 도움 여부를 자동으로 판별하지는 못한다.
- 재작성은 첨삭 이후의 연습이다. GPT 예시를 그대로 옮긴 재작성과 직접 다시 쓴 글을 구별하지만, 둘 다 독립 성장 그래프에 합산하지 않는다.
- 글의 문장 수가 권장 최소에 못 미치거나 영어 8단어/한국어 공백 제외 20자 미만이면 신뢰도를 `low`로 내린다. GPT의 낮은 신뢰도를 앱이 높이지 않는다.
- 낮은 신뢰도·도움받은 글은 결과와 날짜 기록을 보존하되 비교 점수로 쓰지 않는다. 빈 날과 미평가 글은 서로 다른 상태다. 그래프 선은 기록 없는 날을 가로질러 이어 붙이지 않는다.
- 영역별 평균과 변화는 선택한 동일 조건의 최초 독립 평가에 한정한다. 서로 다른 날의 기록이 부족하면 변화량을 만들지 않는다.

## 주간 독립 작문

언어별 한 주(한국 시간 월요일 시작)에 하나의 글을 준비한다. 이전 주와 같은 Level·난이도·분량을 유지하며 다른 생활 주제를 사용한다. 원문을 저장하면 수정할 수 없고, 첨삭 뒤 연습은 재작성으로 남는다. 도움받은 글은 주간 최초 평가로 제출할 수 없다. 이전 주의 같은 조건 평가가 없으면 향상률·점수 변화를 표시하지 않는다.

일반 연습의 Level·난이도·분량은 사용자가 결과를 보고 조절할 수 있다. 일반 연습의 변경은 주간 비교 조건을 바꾸지 않는다.

오류는 실제 GPT 첨삭의 관사·시제·전치사·단복수·어순·표현·연결·논리·맞춤법 분류로 집계한다. 기간 전반/후반의 **글 중 해당 오류가 나온 비율**을 함께 표시한다. 이는 오류 빈도의 비교이며 교사나 검증된 능력 검사를 대체하지 않는다.
