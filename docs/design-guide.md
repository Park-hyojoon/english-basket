## 컴포넌트

- 버튼: 주요 제출·첨삭·완료는 deep green, 저장·새 글은 sage, 부수 동작은 얇은 테두리. 44px 정도의 높이, 키보드 포커스 표시.
- 카드: 기존 테두리·둥근 모서리와 20~25px 패딩. 편집/안내 패널은 1100px 아래 한 열. 원문/비교·자료·점수 세부 정보는 접기를 사용한다.
- 입력: 넓은 textarea와 언어/Level/난이도 select. 최초 글은 성공적으로 고정 저장한 뒤 readonly. 문장/단어 수와 자동 저장 상태를 표시한다. 우클릭·복사·붙여넣기 기본 기능을 유지한다.
- 상태: 저장됨은 ✓, 저장 실패는 ⚠ 및 복구 행동. 알려진 오류를 부정적인 점수 장식으로 강조하지 않는다. 빈 화면은 다음 행동을 짧게 안내한다.
- 차트: 실제 독립 평가만 점과 선, 기록 없는 날에서 선을 끊는다. 0/50/100 축, 기간·단위·조건 표시. hover 상세와 날짜별 버튼/표를 함께 제공해 터치·키보드에서도 조회한다.
- 모바일: 기존 하단 메뉴에 작문을 추가하고 한 열로 배치한다. 차트는 글자를 축소하지 않고 내부 가로 스크롤과 세부 표를 사용한다.
- 애니메이션: 기존 은은한 버튼 효과만 유지하고 `prefers-reduced-motion`에서 끈다.

시안: `tools/writing-preview.html` (작성·첨삭·비교·성장 네 화면). 예시 데이터임을 명시하며 실제 앱의 통계에 쓰지 않는다. 화면 검사 캡처는 요청 시에만 생성한다.
