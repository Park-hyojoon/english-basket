# 데이터 저장과 복구

기존 키 `english-basket-v1`, 바깥 `version:1`, expressions/reviews/sessions/level/settings를 유지한다. 새 선택 필드 `studio`만 확장한다. 이전 백업도 그대로 읽는다. 바깥 스키마 변경·초기화·기존 표현 재등록은 하지 않는다.

## 새 필드

- `studio.version:1`: 작문 확장 버전.
- `writings`: ID, 언어, 일반/주간, 생성·수정일, 주제, Level, 난이도, 목표 분량, 선택 표현의 ID와 당시 스냅샷, 독서 ID, 임시 글, 최초 글·저장일, 작성 방법, 재작성·버전 이력, 첨삭 요청 목록, 결과 입력 임시 글, 학습 상태.
- `readings`: 사용자 입력 자료명·책/권명·위치·짧은 원문·뜻·중요한 표현·메모·수집일·표현 ID. 본문을 다운로드하거나 앱에 책 텍스트를 포함하지 않는다.
- `evaluations`: 평가 ID·작문/요청 ID·최초/재작성·대상 원문·언어·유형·Level·난이도·분량·기준 버전·세부/총점·신뢰도·작성 방법·잘한 점·개선점·흐름·오류·실제 사용 표현 ID·평가일.
- `activeIds`, `preferences`: 언어별 마지막 글과 연습 기본 조건. 한국어 작문 Level은 기존 영어 회화 Level을 올리지 않는다.

요청 시 원문과 평가 조건을 고정한다. 결과의 식별값·언어·Level·난이도·기준 버전·영역별 배점을 검증한다. 같은 요청을 두 번 저장해도 평가는 하나다. 재작성 이후 이전 요청의 결과는 거부한다. 최초 글은 수정·재작성으로 덮어쓰지 않는다.

## 임시 저장

입력 뒤 600ms, 메뉴 이동, 탭 숨김·종료 시 저장한다. 현재 글과 받은 결과 입력도 포함한다. 직접 저장은 최초 작성본을 고정한다. 저장 실패 시 기존 저장값을 덮어쓰지 않고 화면 글을 유지하며 메뉴 이동을 막는다. 실패 안내에서 글 복사·저장 재시도를 안내한다. 오프라인은 글 작성·수집·조회·기존 평가 확인을 지원한다. ChatGPT 첨삭에는 온라인 접속과 계정이 필요하다.

## 백업과 복구

1. 설정 → **백업 받기**: 기존 학습 데이터와 작문·독서·평가·임시 글을 함께 내려받는다.
2. 이전 형식에 처음 저장할 때 `english-basket-before-studio-v1`에 기존 원본을 한 번 보관한다. 설정 → **확장 전 원본 받기**에서 내려받는다.
3. **백업 가져오기**: 기존 기록에 합친다. 원본 입력을 검증하고, 유효하지 않은 백업은 현재 데이터를 바꾸지 않는다.
4. 같은 ID의 작문이 다르면 기존 글을 유지하고 **백업 사본**으로 보관한다. 해당 평가도 사본에 연결한다. 이전 작문 목록에서 모두 열 수 있다. 같은 백업 재가져오기는 사본을 중복 생성하지 않는다.
5. 다른 기기로 옮길 때 각 기기의 백업을 먼저 받는다. 자동 기기 동기화는 없다.

일반 바구니의 두 입력은 유지한다. 독서 메타데이터만 별도 기능에서 추가한다. 복습 횟수는 기존 reviews/evidence에서 확인할 수 있고, 숙달 상태 계산도 유지한다. 개인 글·백업·인증 정보는 Git 저장소와 공개 배포 파일에 포함하지 않는다.

코드 복구 기준은 `recovery/pre-writing-studio-20261009`다. 코드 복구는 사용자 브라우저 데이터를 되돌리지 않으며, 데이터 복구에는 내려받은 백업을 사용한다.
