# Writing Studio 통합 계획

2026-10-09 · 복구 기준: `recovery/pre-writing-studio-20261009` (`9c1d4d3`).

목적: 직접 작성 → 기존 ChatGPT 계정에서 첨삭 → 다시 작성 → 같은 조건의 기록 비교.
정적 PWA·오프라인 편집·기존 브라우저 저장 키와 영어 학습 기능을 유지한다. AI 호출·API 키·자동 결과 회수는 추가하지 않는다.

기존 수집·복습·대화 결과·Level·숙달·백업은 구현되어 있다. 복습은 로컬 상황 지시문이고 GPT의 개별 첨삭은 없으며, 회화 시간은 직접 입력한다. 자동 동기화와 실제 장기 기억 측정은 구현되지 않았다. 새 작문 기능도 GPT 평가를 학습 참고 기록으로 표시한다.

1. 기존 화면의 아이보리·녹색·사이드바를 계승한 기본/첨삭/비교/성장 시안.
2. 별도 작문·독서·평가 모듈을 기존 v1 저장 형식에 선택 확장. 기존 원문과 기록은 변경하지 않는다.
3. 최초 원문을 잠그고 첨삭 요청마다 식별값·평가 조건·대상 글을 고정. 잘못된 결과·중복·구버전 결과를 거부.
4. 영어/한국어, 일반/주간, 독립/도움받은 작성, 최초/재작성을 구분. 같은 Level·난이도·분량·기준 버전만 비교.
5. 실제 데이터로 7/30/90일 그래프·영역별 변화·반복 오류·주간 보고서를 표시.
6. 이전 백업·저장 실패·오프라인·모바일·기존 회화와 새 학습 흐름을 검증한 후 배포.

주요 위험: 외부 GPT 응답 형식 오류, 브라우저 저장 용량, 도움받은 글의 성장 과대평가, 다른 기기 백업 충돌. 원본·임시 글 보존, 엄격한 결과 검증, 비교 그룹 분리, 충돌 사본 보존으로 처리한다.

일반 바구니의 두 필드는 유지한다. 출처는 새로 요청된 독서 발췌 기능에서만 선택 입력한다. 책·성경 본문을 앱에 제공하지 않고 사용자 입력만 보관한다.

첨부에는 기획서 텍스트만 있다. 언급된 화면 4장 대신 현재 실제 화면을 기준으로 삼는다. 글자 크기 충돌은 사용자에게 결정 요청 중이다.
